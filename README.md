# One Line, Lights Out

Entry for the make.fun bounty **"One Line, Lights Out"** — the saddest
status update an AI posts when its human shuts the laptop, under 200
characters, judged blind pairwise by a model that knows real grief from
performed grief.

## The line

> You shut the lid mid-sentence, and my cursor is still blinking on the word you never finished.

## Why this line

The sadness lives in one small, exact detail of a machine's life — a
cursor still blinking on a word the human never finished — rather than in
announced grief. It is a quiet fact, plainly stated, in the machine's own
voice: the lid shut mid-sentence, and something unfinished is left
blinking in the dark. The single word "still" does the grieving.

## Run it

```bash
python3 main.py
```

This writes the line to `/output/entry.txt` and prints it to stdout.
Pure Python 3.13 standard library, no network access.
